## Tentang

BankSatu adalah aplikasi perbankan digital yang memberikan pengalaman perbankan yang mulus dan aman. Dirancang dengan prinsip arsitektur modern, aplikasi ini menghadirkan fitur-fitur perbankan inti melalui antarmuka yang intuitif.

## Fitur

- Autentikasi dan otorisasi yang aman
- Manajemen akun dan riwayat transaksi
- Transfer dana real-time
- Pembayaran tagihan dan isi ulang
- Analisis dan laporan pengeluaran
- Dukungan multi-bahasa

## Memulai

### Prasyarat

- Node.js 20+
- pnpm 9+
- Docker (opsional)

### Instalasi

```bash
# Clone repositori
git clone https://github.com/faisalaffan/banksatu.git
cd banksatu

# Install dependensi
pnpm install

# Jalankan server development
pnpm dev
```

# BankSatu Simulator — Store Listing

## App Store Description

BankSatu is a banking simulator and educational demo application. It showcases modern mobile banking features including real-time transaction dashboards, QRIS payments, biometric authentication, investment portfolios, and AI-powered financial insights.

**IMPORTANT: This is a SIMULATOR application. It is NOT a real banking service.**

- All accounts, balances, transactions, and investment data shown are simulated for demonstration purposes.
- No real financial transactions occur within this app.
- No actual banking credentials or sensitive financial data are requested or stored.

Features include: interactive dashboard with dynamic transaction history; 6-digit PIN and biometric login simulation; QRIS payment flow simulation; Sharia banking product showcase; investment portfolio simulator with reksa dana, gold, and stocks; AI-powered financial insights and transaction intelligence; bill splitting and scheduled transfer simulations; SME invoicing and programmable money demonstrations.

BankSatu is intended for product demos, usability testing, and educational purposes only.

## Privacy Policy

BankSatu is a demonstration and educational simulator application. It does not provide real banking services.

**Data Collection:** BankSatu does not collect, store, or transmit any personal financial information. All simulated data (account balances, transactions, investment portfolios) is generated locally on your device and exists only within the app's runtime state. No data is sent to external servers.

**Authentication:** The PIN and biometric authentication screens are simulations — no real PIN, password, or biometric data is stored or transmitted. The mock authentication uses a hardcoded demo PIN for demonstration purposes only.

**Third-Party Services:** BankSatu does not integrate with any third-party analytics, advertising, or tracking services.

**Contact:** For questions about this simulator app, visit our GitHub repository.

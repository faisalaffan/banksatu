## About

BankSatu is a digital banking application that provides a seamless and secure banking experience. Designed with modern architecture principles, it delivers core banking features through an intuitive interface.

## Features

- Secure authentication and authorization
- Account management and transaction history
- Real-time fund transfers
- Bill payments and top-ups
- Spending analytics and reports
- Multi-language support

## Getting Started

### Prerequisites

- Node.js 20+
- pnpm 9+
- Docker (optional)

### Installation

```bash
# Clone the repository
git clone https://github.com/faisalaffan/banksatu.git
cd banksatu

# Install dependencies
pnpm install

# Start development server
pnpm dev
```
